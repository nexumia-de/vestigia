# Vestigia

*Vestigia* is Latin for footprints, traces.

Adaptive GTK4/libadwaita app for [Phosh](https://phosh.mobi/) phones
and the desktop that works with a self-hosted
[Dawarich](https://dawarich.app/) server: see your location history
(tracks, visits, statistics) on a map, and record your phone's position
and upload it to your own server.

Status: planning (milestone M0). Nothing to install yet. See the
[milestones](https://github.com/nexumia-de/vestigia/milestones) and
[docs/roadmap.md](docs/roadmap.md).

Vestigia is an independent project and not affiliated with Dawarich.
Your location data goes only to the server you configure. Map data:
© OpenStreetMap contributors.

[phosh-toolkit](https://github.com/nexumia-de/phosh-toolkit), checked out
next to it:

git clone https://github.com/nexumia-de/vestigia.git
